# SomehowConvert

**Convert almost anything. Somehow.**

SomehowConvert is a free online file conversion website with simple browser-based tools.

### Tools
- PNG → JPG
- JPG → PNG
- WEBP → PNG
- Image → PDF
- TXT → PDF
- CSV → JSON
- JSON → CSV
- HTML → PDF
- Image → WEBP
- Image → PNG
- Image → JPG
- Compress Image
- Resize Image
- Rotate / Flip Image
